New design lab / description embeddings

Every film has coordinates.

Embed one synopsis per film, keep similarity calculations in the original vector space, and use UMAP only to create a navigable two-dimensional view. Picker colors become a temporary lens over the same stable movie map—not a permanent property of each film.

01 / ResolveMatch titlesCriterion title + year + director → one canonical external movie ID.
02 / DescribeCollect textOverview or plot plus genre, country, decade, director, and format metadata.
03 / EmbedCreate vectorsOne normalized semantic vector per unique film; cache it and regenerate only when text changes.
04 / ProjectDraw the mapCosine distance remains canonical. UMAP produces display coordinates and local neighborhoods.

How to determine similarity

A hybrid taste vector

No single signal is trustworthy enough. Exact overlap rewards shared favorites but misses spiritually similar picks. Embeddings catch meaning but can flatten eccentricity. The strongest model blends both, downweights giant box sets, and explains every match in plain language.

01Build one profile per film from synopsis, director, country, language, movement, decade, and collection notes.
02Embed every film, then create a rare-pick-weighted centroid for each Closet visit.
03Deduplicate films within a visit and cap box-set influence so one purchase cannot dominate.
04Blend cosine similarity with exact overlap, director affinity, and distribution distance.
05Project the pairwise matrix into two dimensions with UMAP for the overview map.
06Generate evidence: shared films, adjacent films, common directors, and strongest differences.
